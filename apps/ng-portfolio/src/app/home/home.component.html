I've been working professionally as a software developer since 2015 with a focus in Angular development. I followed along with tutorials in the Angular Beta, which was interesting since many tutorials and documentation were quickly outdated by changes in syntax prior to the full release. When Angular was released I was ecstatic because everything just clicked for me, and over ten years later it still does. My first big Angular project was piloting an Angular 2 application inside of a .NET application at Marketsharp. Since then I've led the front-end on everything from a COVID-19 testing site that serviced multiple states to a healthcare provider application at Optum.


Today I'm a Senior Front-End Engineer at DroneSense, where I've led the rebuilds of four of our Angular applications, including our mission-critical live operations client for viewing real-time drone video and telemetry on a map. I also built a translation automation system that works across all of our Angular apps, and I've become the go-to developer for starting new projects. In 2026 I moved to an AI-native workflow, and much like when Angular first came out, it's changed how fast I can learn and build.


This site was created using an NX monorepo with Angular 22, NestJS, and MongoDB.
